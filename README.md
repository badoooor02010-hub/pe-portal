# أبحاث ومشاريع التربية البدنية - المتوسطة الثانية

لوحة مشاريع تفاعلية (بأسلوب Padlet) لمشاريع وأبحاث التربية البدنية،
إشراف الأستاذة بدرية المالكي. مبنية بـ React + Vite + Tailwind CSS.

- **البيانات والدخول:** Firebase Firestore + Authentication
- **تخزين الملفات:** داخل Firestore نفسها كـ Base64 — بدون Storage وبدون
  Cloudinary وبدون أي إعداد فوترة (حد الملف ~700KB، والصور تُضغط تلقائياً)

## التشغيل محلياً

```bash
npm install
npm run dev
```

يعمل الموقع فوراً في **وضع المعاينة** (تُحفظ البيانات في متصفحك) حتى بدون
إعدادات — مفيد لمعاينة التصميم والتجربة.

## الربط الفعلي — Firebase فقط

1. أنشئي مشروعاً على [Firebase Console](https://console.firebase.google.com)
   ثم أضيفي تطبيق Web وانسخي إعداداته.
2. انسخي `.env.example` إلى `.env` واملئي قيم `VITE_FIREBASE_*`.
3. فعّلي الخدمات في وحدة التحكم:
   - **Authentication** → فعّلي Email/Password، ثم أضيفي حساب المعلمة
     (Users → Add user).
   - **Firestore Database** → أنشئي قاعدة البيانات.
4. انسخي محتوى `firestore.rules` إلى Firestore → Rules.
5. أعيدي تشغيل `npm run dev`.

> ملاحظة: لا حاجة لتفعيل Firebase Storage إطلاقاً — الملفات تُحفظ كنصوص
> Base64 داخل مستندات Firestore مباشرة.

### حدود الملفات

الحد الأقصى للملف الواحد **20MB**. نظراً لأن مستند Firestore محدود بـ 1MB،
تُحفظ الملفات بطريقتين:

- **حتى ~700KB:** تُخزن كنص Base64 داخل مستند المشاركة مباشرة.
- **أكبر من 700KB:** تُقسم تلقائياً إلى أجزاء (chunks) داخل مجموعة فرعية
  وتُعاد تجميعها عند العرض — تدعم الصور والفيديو وPDF وWord.
- **الصور:** تُضغط تلقائياً داخل المتصفح قبل الحفظ عند الحاجة.

## الصلاحيات

| الدور | المشاركات (ثاني/ثالث متوسط) | الاستراتيجيات |
|------|------------------------------|----------------|
| طالبة/زائر | قراءة + إضافة فقط | قراءة فقط |
| المعلمة (مسجلة) | قراءة + تعديل + حذف | تحكم كامل |

## البناء للإنتاج

```bash
npm run build
```

الناتج في مجلد `dist/` — يمكن استضافته على Firebase Hosting (الخطة المجانية)
أو Netlify أو أي استضافة ثابتة.
